# Портфолио проектов по продуктовой аналитике

Привет! Я Сергей, продуктовый аналитик. Этот репозиторий содержит мои учебные и исследовательские проекты, которые демонстрируют мои навыки в области анализа данных, статистики и визуализации.

## 🛠️ Используемые инструменты
- **Языки:** Python (pandas, numpy, matplotlib, scipy, statsmodels), SQL
- **Базы данных:** PostgreSQL, ClickHouse
- **BI-инструменты:** Power BI, Superset
- **Другое:** Git, Airflow, Google Sheets

## 📂 Структура портфолио
- **[A/B-тестирование](ab_testing):** Проекты по дизайну и анализу экспериментов (t-test, бутстрап, линеаризация).
- **[SQL-запросы](sql_analysis/):** Примеры сложных запросов с оконными функциями и оптимизацией.
- **[Дашборды](dashboards/):** Примеры визуализаций в Power BI и Superset.
